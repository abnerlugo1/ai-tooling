Matriz de Decisión y Criterios de Selección

Guía de Ingeniería
Dimensión Arquitectura Basada en API Arquitectura de Modelo Integrado Recomendación Típica
Modelo de Costos OPEX puro: Paga por token consumido (Prompt + Completion). CAPEX / Hardware: $0.00 por token; amortización por infraestructura. API para tráfico variable; Integrado para volumen masivo y continuo.
Requisitos de Hardware Mínimos (cualquier microservicio o navegador ligero; <50 MB RAM). Elevados: Exige 4GB a 32GB de RAM/VRAM según cuantización (GGUF). Integrado en servidores on-prem o edge devices dedicados.
Latencia y Red Sujeto a RTT de red, jitter de internet y colas de inferencia externa. Predecible y ultra-rápido en TTFT; sin latencia de tránsito WAN. Integrado cuando se requiere tiempo real estricto en el borde.
Privacidad y Compliance Datos viajan a infraestructura cloud de terceros (requiere DPA/BAA). Air-Gapped completo; datos sensibles jamás abandonan el proceso local. Integrado para defensa, banca confidencial y registros médicos.
Capacidad de Modelo Acceso a modelos de frontera masivos (Claude 3.5 Sonnet, GPT-4o). Acotado a modelos SLM compactos (1B - 14B parámetros). Híbrido (Dracula Pattern): Clasificación local + razonamiento complejo en API.
